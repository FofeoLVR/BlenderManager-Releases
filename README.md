# BlenderManager — Windows builds

This repository distributes compiled Windows builds of BlenderManager only.

The source code is not published here.

## Download

Open [Releases](../../releases), choose a version, download its ZIP archive, extract it and run `BlenderManager.exe`.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- Blender is not included. It can be detected or downloaded from inside BlenderManager.
